DSH PLUGIN · 用量观测

Token Usage

在 DSH 桌面端 / Web 端侧边栏左下角加一个 Token 统计面板。 所有数字只来自本机 Session 日志，不访问外部服务、不上传、不改配置——会话归档或删除后，历史仍然在。

  • MIT
  • 本地 · 只读 · 不上传
  • 按 provider usage
  • 不挑后端

亮点

  • 按实际用量：统计 provider 上报的 usage，不做字符数估算。
  • 不挑后端：DeepSeek、GLM、Kimi……只要 Session 里留下 provider usage 就统一计入，不绑定单一供应商。
  • 一眼看全：左下角常驻今日用量；面板第一行是全部历史总量，下面是 365 天 GitHub 风格热力图。
  • 明细够用：每天的总量、输入 + 输出、缓存读取、缓存写入和会话数。
  • 不只 token：全部历史的轮次、步骤和平均生成速度（tok/s）。
  • 安全可靠：账本用临时文件 + 原子替换写入，文件损坏时保留 .corrupt-* 备份。

安装

要求 DSH Desktop / Web 已安装，且 profile 里已启用 @deepseek-ai/dsh-base。

# 从 GitHub 安装
dsh plugin --profile desktop add github:ai-v5/LLMDSHPlugin_token-usage

# 或从 npm 安装
dsh plugin --profile desktop add llm-dsh-token-usage

# 或从本地目录安装
dsh plugin --profile desktop add D:\WORK\ai-v5\LLMDSHPlugin_token-usage

安装后重启 DSH Desktop，入口出现在左侧栏底部、Settings 上方。终端里没有 dsh 命令时， 用桌面版安装目录下的 resources\runtime\runtime\cli\bin\dsh.cmd（以实际安装布局为准）。 卸载：dsh plugin --profile desktop remove llm-dsh-token-usage。

关于「网络」能力标签

插件市场会把带前端界面的插件扫出 network 标签。这里的 network 只来自浏览器端的一次同源请求：

GET /api/llm-token-usage/stats

目标是本机 DSH Host 自己注册的路由，读取本机 Session 日志；不访问任何外部域名，不上传任何数据， 不含遥测、统计或授权检查。Host 端的 fs-read 用于读 Session 日志，fs-write 只写 ~/.dsh/token-usage-ledger.json 这一个文件。
