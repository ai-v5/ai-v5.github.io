DSH PLUGIN · 侧边栏工作流

Aside（旁白）

在右侧栏里开一个真正分叉的旁聊：从当前对话分出一支，就在终端标签旁边， 你可以继续问、继续改，而主线程一个字都不会被写进去。

  • AGPL-3.0-or-later
  • DSH ≥ 0.2.1-rc.5
  • 侧边栏标签页
  • 真正的 fork 会话

它解决什么问题

编码过程中经常有「顺手再问一句」的需求：这段报错要不要改？换个思路行不行？但如果直接在主线里问， 追问会污染上下文，模型的下一步动作也会被带偏。旁聊把这条支线挪进侧边栏：它有自己的历史、 自己的模型、自己的工具和 composer，主线程保持原样。

你会得到

  • 新建旁聊：右侧栏起始页多一张卡片，就在「新建终端」上方，点击即把当前对话 fork 成新标签页。
  • 真的分叉，不是复制粘贴：新标签是一个真实子会话，历史从主线程复制到最后一个完成的轮次。
  • 随便聊：提问、纠正、打断都不会回到主线程；主线程下一轮不受任何影响。
  • 活得比这次会话久：标签页随侧边栏布局一起保存，刷新、重启后仍在那儿。
  • 像终端一样停靠：可停靠、分屏、浮动、全屏，行为与终端标签一致。

安装

# 从本地 checkout 安装到你的 profile（README 用 web，桌面端换成 desktop）
dsh plugin --profile web add C:\path\to\dsh-plugin-aside

# 或者直接从 GitHub
dsh plugin --profile desktop add github:ai-v5/dsh-plugin-aside

装完重启 DSH Desktop —— 替换进去的包需要新一代 JavaScript generation 才会生效，刷新浏览器不够。

依赖 DSH >= 0.2.1-rc.5（暴露 ctx.sessions.fork 的那个版本）。 本地目录安装是 link: 依赖，改了插件源码之后同样要重启 DSH 才会生效。
