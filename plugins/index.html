怎么安装

DSH 0.2.x 自带插件管理命令，装上之后重启 DSH：

# Token 使用面板（npm / GitHub 均可）
dsh plugin --profile desktop add github:ai-v5/LLMDSHPlugin_token-usage

# 旁白（本地 checkout）
dsh plugin --profile desktop add C:\path\to\dsh-plugin-aside

# 免密钥检索：组合包是仓库里的 extras/dsh-provider，不是仓库根目录
dsh plugin --profile desktop add D:\path\to\keyless-web-mcp\extras\dsh-provider

keyless-web-mcp 的仓库根是一个 Python 项目，DSH 组合包在 extras/dsh-provider/ 里（包名 dsh-plugin-keyless-web）。 所以它走下面的市场索引安装最省事，或者像上面这样直接指向那个目录。

终端里没有 dsh 命令时，用桌面版安装目录下的 resources\runtime\cli\bin\dsh.cmd。装完必须重启桌面端——模块需要新一代 JavaScript generation 才会生效，刷新浏览器不够。
